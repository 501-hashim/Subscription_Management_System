# Brightloop Subscription Management System – Frontend
> **Odoo X Make-A-Ton Virtual Hackathon Project**  
> *Vite + React 18 + Tailwind CSS Prototype*

---

## 📌 Overview

The frontend layer provides a responsive, enterprise-grade SaaS user interface for managing customers, subscription plans, commercial quotations, active contracts, recurring invoices, payment transactions, and financial reports.

---

## 🚀 Setup & Execution

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Compile production build
npm run build
```

The application runs on `http://localhost:5173`.
